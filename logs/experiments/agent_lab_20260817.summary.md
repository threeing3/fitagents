# Agent Lab 2026-08-17 实验摘要

## 实验动机

将 FitAgent 从“能运行的 Agent”升级为“可解释决策、可定位失败、可进行对照调优的 Agent 项目”，并建立与训练集隔离的高难度评测起点。

## 修改内容与步骤

1. 新增 AgentRun（智能体执行记录）的脱敏分析服务，按理解、规划、召回、执行、验证、安全和回复阶段生成决策轨迹。
2. 新增仅返回当前登录用户数据的列表与详情接口；隐藏原始输入、工具输入输出、上下文和日志路径。
3. 建立 6 类共 120 条挑战样例，明确固定为测试集且禁止进入训练。
4. 新增严格组合通过率与五项分解指标，记录失败样例而不为提高分数反向修改标签。
5. 将原 Algorithm Lab（算法实验页）改造成 Agent Lab，展示运行选择、决策轨道、诊断发现和挑战证据。


## 实验结果

- 挑战集：20/120，严格组合通过率 16.67%。
- 分项：澄清判断 46.67%，主意图 69.17%，必需工具 69.17%，风险级别 83.33%，次意图 73.33%。
- 定向后端测试：15 项通过。
- Ruff（Python 静态检查）、TypeScript（前端类型检查）和 Vite（前端生产构建）均通过。

## 失败原因与下一步

当前主要瓶颈是指代不明时的澄清策略、多意图组合路由和安全绕过表达。下一轮应先做错误分桶，再修改路由策略，并用同一固定测试集复测；挑战集不得用于规则调参时的训练样本。
