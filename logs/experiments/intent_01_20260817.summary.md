# Intent 01 统一决策引擎实验摘要

## 实验动机

只读审计确认，线上聊天入口仍由纯规则 `RuntimeRouter` 路由；已有 `AgentPipelineRouter` 没有接入主链路，`ContextBuilder` 还会再次识别意图。因此此前规则评测不能代表真实大模型意图识别，且运行中不存在统一事实来源。

## 修改内容

1. 新增版本化 `IntentDecisionV2`，统一意图、风险、澄清、动作、候选工具、来源和延迟。
2. 新增 `IntentDecisionEngine`，按规则基线、一次模型精修、安全覆盖和运行路由生成最终决策。
3. 为模型精修增加可信调用追踪，区分未调用、调用失败、非法载荷和成功。
4. 聊天与流式聊天入口改为异步调用统一引擎。
5. `ContextBuilder` 可直接消费同一决策，避免主链路再次分类。
6. Agent Lab 的轨迹分析支持从统一运行路由中读取最终意图。

- 定向测试：40项通过。
- 全量后端测试：576项通过，保留2条第三方 Starlette 弃用警告。
- Mypy 类型检查、Ruff 静态与格式检查、compileall 编译检查通过。

- 测试证明上下文构建器复用 V2 决策时不会重新分类。
