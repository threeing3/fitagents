# Intent 04：Qwen3-4B 训练前预检

## 实验动机

将 FitAgent 的意图识别从 DeepSeek API 基线升级为可独立部署和后训练的 Qwen3-4B，
同时保证固定挑战集隔离、助手回复损失和确定性安全下限。

## 修改内容

- 底座配置切换为官方 Qwen3-4B，训练依赖要求 Transformers 4.51 以上。
- 新增训练/验证数据分离、真实聊天模板和仅助手回复标签。
- 新增不可覆盖运行记录、50 条烟雾子集、断点恢复、环境与适配器校验和。
- 新增原始底座与 Adapter 共用的固定挑战集评测入口。
- 新增运行完整性验证器和 Adapter 新进程重载门禁；训练结束本身不再视为成功。
- 修复 AutoDL 可移植性：远程命令不再包含 Windows 绝对路径，并兼容远程运行器的证据目录协议。

## 执行命令与步骤

1. 生成 800 条训练 SFT 数据和 100 条验证 SFT 数据。
2. 运行配置 dry-run，记录行数和 SHA-256 校验和。
3. 在项目本地隔离环境安装 Transformers 4.57.6 与 Jinja2 3.1.6。
4. 下载官方 Qwen3-4B 分词器配置，不下载完整模型。
5. 对 900 条样本执行真实聊天模板和助手损失掩码预检。
6. 运行定向静态检查、类型检查和单元测试。

## 实验结果

- dry-run：训练 800 条，验证 100 条，模板家族无交叉。
- 全量分词预检：900/900 成功，无助手标签 0 条，截断 0 条。
- 最大长度 144 Token，中位长度 117 Token，助手标签为 45–54 Token。
- 首次原生掩码尝试失败：官方模板没有 generation 标记，且本地缺少 Jinja2。
- 修复为官方模板助手边界法后，真实首条样本 114 Token，其中 66 个被屏蔽、48 个参与损失。
- 完整后端回归测试 601 项全部通过；保留 2 条第三方弃用警告。
- 已创建 45 文件的内容寻址远程快照。初版 `7895c6367976a64a86f0` 在验证器增强后保留为历史；
