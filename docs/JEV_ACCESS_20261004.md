## 本轮实现
候选客户端不自动读取密钥，不改.env和依赖。统一决策引擎现已支持显式注入客户端，默认不启用。
每次请求13种任务的独立五选一判断及当前风险判断，保留否定/背景/不明确状态。
任务定义包括训练记录纠正（候选层扩展，不直接映射现有意图目录）。
缺字段、概率异常、版本漂移、鉴权失败等整体拒绝，不将合法格式当语义正确。
任务特定门槛与中文效果尚未校准，默认退出策略拒绝接受；候选summary的exit_authorized始终false，真实退出另见provenance.jev_exit。
退出策略仅允许调用方显式提供的已审核只读校准范围，不能启用训练记录或纠正等副作用任务。
未校准、任务集合不确定、否定/背景/模糊指代、风险与规则冲突时升级原有模型。
测试里的校准配置为模拟控制例，不是中文实测结果，也未用于业务启动。

## 使用
离线检查：`.venv\Scripts\python.exe scripts/check_jev_intent.py`
手动真实检查：`.venv\Scripts\python.exe scripts/check_jev_intent.py --live`
真实模式通过隐藏输入获取密钥，最多5条合成请求，无自动重试；首次失败停止。
不要把密钥粘到聊天、命令参数或版本库。脚本不保存密钥。
检查脚本将合成题、指定边界字段预期、候选、词元与估算费用写入logs/experiments/jev_probe_时间.jsonl，不保存密钥。
默认预算0.02美元，以固定模型64k输入上限逐调用预留预算；最多5条，无重试，失败停止。
费用是按2026-10-04官方单价估算，不代替平台账单；指定字段比较不是完整语义验收。
后续拿到账号额度后先检查中文否定、引用、复合请求、指代和纠正，再决定是否接入级联路径。
