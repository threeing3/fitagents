# 自主训练工作台：第一轮实现

## 产品立场

保留 FitAgent 品牌，但不将它称作健身教练。用户拥有目标、日期、运动选择及最终决定；系统整理记录、提供候选建议并执行明确授权的操作。不修改已有聊天历史。

## 三个方向在原产品的映射

- 对话：保留原会话、流式回复及执行依据，增加目标与下一步侧栏。
- 概览：本周真实日历、用户选择的下一步、原始状态记录及已有业务信息。日历不代表已完成训练；不展示未经验证的准备度评分。
- 训练记录：原记录及更正组件，增加“计划与调整”标签；复用原有长期跟踪、审批及执行历史组件。桌面并列显示跟踪与审批，窄屏单列。标签切换保留草稿。

## 明确没有做的事

没有按照图片虚构完整周训练安排或草案，没有变更数据库接口及后台算法，没有调用付费模型，没有部署或推送。图片中的周计划表尚未接入完整的按日期计划读取接口；目前显示可验证的跟踪与审批数据，不能声称第三张图已完整逐项复刻。

## 已验证与下一轮

类型检查通过，35 项前端测试通过，生产构建通过。已在隔离合成数据库登录检查对话、概览、训练记录及审批历史。新增测试覆盖空日计划入口导航、零值反馈与标签草稿保留。视觉验收见项目根目录 design-qa.md；未通过之前不能将构建通过等同于完整设计交付。

上述第一轮缺口已在后续实现补齐：账户时区、当前计划读取、日期计划表、原计划与候选快照差异、对话与今日待审阅入口。同状态合成草案和窄屏验收已完成，当前融合范围见design-qa.md的passed结论。第一轮未完成描述保留作为历史，不代表最新状态。下一轮按实际使用删减重复入口和指标卡片。
