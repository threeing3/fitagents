# FitAgent 展示与验收指南

让读者看清：用户能做什么、系统怎样执行、哪些事实可以核验。截图展示交互，测试检查协议与业务状态，真实模型评测检查模型行为，三者不混为一谈。

## 五分钟阅读顺序

1. [首页](../README.md)：产品场景与四条主线。
2. [架构](ARCHITECTURE.md)：宿主、模型和领域子任务如何分工。
3. [复盘交接](../fast_api/app/services/review_collaboration.py)：证据检查与失败阻断。
4. [记忆依赖测试](../tests/test_memory_dependencies.py)：纠正如何使派生记忆失效。
5. [任务级验收](../algorithm/evaluation/fitagent_journey_eval.py)：检查最终业务状态，而不只是文本。

## 本地演示路线

按[快速开始](GETTING_STARTED.md)准备隔离空库与合成账号。不要公开真实健康信息、模型密钥或私人日志。

| 步骤 | 操作 | 应关注的结果 |
| --- | --- | --- |
| 建档与记录 | 输入合成档案与训练记录 | 缺失信息追问；记录可在原有页面查询 |
| 查询与建议 | 查询历史，提出日期或运动类型约束 | 使用哪些有效事实；哪些动作仍是候选 |
| 更正事实 | 选择明确记录，修改支持字段并确认 | 事实更新，旧记忆退出召回，派生判断失效 |
| 周期复盘 | 请求训练、饮食与恢复复盘 | 分析、领域建议与规划交接；子任务不能写计划 |
| 审批与历史 | 查看调整、批准或拒绝、展开记录 | 批准前不变更；历史读取不重跑 |
| 故障边界 | 专项测试证据变化、重复请求与异常 | 失败明确记账，不伪造完成、不重复写入 |

不同变更支持的字段、表达与审批范围不同。训练更正覆盖时长、主观用力程度和完成状态，不修改每组动作明细；演示时选择明确记录，不冒充通用纠正能力。

真实模型与领域分析需要自己的模型接口；离线明确显示跳过。后台责任需要单独工作进程，不是打开页面后自动持续执行。

## 执行记录怎么看？

回复旁展开“完整执行追踪”，查看步骤、工具结果、验证及子任务关联。重新打开会话可读取明确关联的运行；审批后刷新只查询日志，不重新执行。

已记录输入可能是摘要或受限片段，不是完整模型上下文。日志步骤完成与业务提交分别核验，未知结果不能当失败直接重试。见[追踪指南](EXECUTION_TRACE_GUIDE_20261004.md)和[验收矩阵](TRACE_ACCEPTANCE_MATRIX_20261005.md)。

复现旧图：构建前端，启动仅本机预览端口4181，执行 node web/scripts/capture-showcase.mjs（合成展示截图脚本）。脚本拒绝覆盖既有截图，不发送模型请求。它不是另一个完整产品，也不是当前全部页面的最新截图。

## 评测与证据入口

| 层次 | 数据与执行方式 | 核验内容 | 不说明什么 |
| --- | --- | --- | --- |
| 协议回归 | 合成输入、受控模型替身 | 权限、参数、生命周期、交接与异常 | 真实模型理解质量 |
| 任务级业务链路 | 固定合成任务与隔离数据库 | 纠正、审批范围、重复提交与最终状态 | 真实用户收益、线上泛化 |
| 工具循环模型评测 | 真实模型；部分故障人为注入 | 协议读取、异常恢复与结果使用 | 全业务整体验收 |
| 页面及重启专项 | 原有页面或真实处理器、隔离数据 | 可见状态、归属、记录与提交关系 | 完整公网部署或容量承诺 |

- [固定业务链路](../algorithm/evaluation/fitagent_journey_eval.py)：数据显式为合成评测，不用于训练。
- [工具循环评测](../algorithm/evaluation/tool_loop_task_eval.py)：区分脚本模型与真实调用；合成工具不是业务集成。
- [记忆评测集](../tests/evals/hindsight_memory_eval_cases.json)、[依赖失效测试](../tests/test_memory_dependencies.py)。
- [领域测试](../tests/test_domain_subagents.py)、[子任务运行测试](../tests/test_subagent_runtime.py)、[成熟度清单](SUBAGENT_MATURITY_20261004.md)。
- [历史交付记录](FITAGENT_DELIVERY_20261003.md)、[验收范围](FITAGENT_FINAL_SCOPE_AUDIT_20261003.md)：属于当时版本，不代表本轮重跑全量测试。
- [评测协议](EVALUATION_PROTOCOL.md)：历史评分和实验组织，实际入口以当前代码为准。

不以测试数量、回答长度或步骤数证明效果；未宣称多智能体优于单智能体的量化收益。

## 模型密钥边界

tests/test_local_byok.py（自带密钥入口测试）使用虚构凭证，检查空密钥、旧配置隔离、离线清空与迁移确认，不发起真实模型请求。运行行为见[密钥说明](MODEL_ACCESS.md)。
