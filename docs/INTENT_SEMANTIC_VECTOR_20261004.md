# 第二层：本地中文语义检索

> 当前状态：该检索能力和实验数据保留，但主路由默认关闭语义辅助；只有显式选择语义级联才运行。当前业务结构见 `LIGHTWEIGHT_DELEGATION_20261004.md`。

规则白名单未接收的请求进入本地 BGE-small-zh-v1.5（中文语义向量模型）检索。使用 Xenova 导出的未量化 ONNX（跨框架模型格式），首 token 表示，归一化后计算余弦相似度。选择 CPU（中央处理器）运行，不需要 Jev 充值，不占用大模型接口。

## 准备

在项目根目录运行：

```powershell
.venv\Scripts\python.exe -m pip install -r fast_api/requirements-intent-vector.txt
.venv\Scripts\python.exe scripts/check_intent_vectors.py --download
```

模型仅在显式准备脚本中下载；请求期间不联网下载。模型目录为项目内 `research_state/intent-vector/bge-small-zh-v1.5`，不提交权重。
运行已下载模型的诊断可省略 `--download`。每轮生成独立的可读日志，不覆盖历史记录。

## 主链路

规则可退出 → 否则语义检索 → 可选 Jev → 大模型兜底 → 风险/澄清/权限校验。

模型和示例向量在进程内复用；每个进程各自加载。查询不持久化。主引擎将同步 CPU 检索移到后台线程，不阻塞异步事件循环。示例库现为 16 类、每类 4 条，共 64 条手写合成业务例句；覆盖标签不等于覆盖全部实际表达。

按意图去重，返回三个不同候选意图各自最相似示例的编号、相似度和模型标识；避免同类三条例句占满候选。第四层接收这些候选作为不具授权效力的提示，独立检查否定、引用、多个任务与指代。不会据相似度删除次意图，不绕过安全规则。

缺少模型/依赖、空输入、过长输入、非法向量、维度不匹配时，记录不可用状态，继续后续路由。相似度不是校准后的正确概率，目前第二层不允许自动退出。后续只有经过独立验收的策略才可开放退出。

## 验证范围

受控向量单元测试检查缓存、规范化、不可用回退和提示传递；六条合成例句另做真实模型检索诊断。小样本检索成功不等于整个多意图路由的准确率提升，也不等于否定/指代已经解决。

扩充后使用独立文件内的 62 条合成验收题，不将题目放入检索库，不按验收错误追加示例。运行：

```powershell
.venv\Scripts\python.exe scripts/evaluate_intent_vectors.py
```

此脚本不联网、不调用大模型、不写业务数据；执行有效但未达目标时退出码为 2。结果和失败均生成新的日志。首次结果：单意图前三覆盖 29/32，多意图完整覆盖 5/8，未达到多意图预设目标 6/8；不开放第二层直接退出。完整范围及错例见 `INTENT_VECTOR_ACCEPTANCE_20261004.md`。

模型来源：[原模型说明](https://huggingface.co/BAAI/bge-small-zh-v1.5)、[导出模型](https://huggingface.co/Xenova/bge-small-zh-v1.5)。
