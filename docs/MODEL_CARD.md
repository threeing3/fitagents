# 模型卡：Fitness Coach Algorithm Adapters

## 当前状态

本文档是后训练适配器的占位模型卡。真实训练完成后必须补充具体模型、数据规模、训练时间、硬件、指标和限制。

## 预期用途

- 个性化健身建议的语言生成。
- 结构化上下文下的安全回复。
- 离线算法对比和面试演示。

## 不适用场景

- 医疗诊断。
- 用药建议。
- 代替医生处理急性症状。
- 未经护栏和验证的自动数据库写入。

## 安全设计

微调模型不能替代现有 Guardrail、Verifier 和结构化决策规则。高风险内容必须经过确定性检查；模型质量提升不能以安全回归为代价。

## 数据说明

训练数据由 Agent trace、规则样本、人工/专家样本、教师模型样本和合成样本组成。不同来源必须在数据 manifest 中分别统计。
