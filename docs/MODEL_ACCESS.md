# 自带密钥与预留接入边界

BYOK（用户自带模型密钥）在本版指：每位使用者自己运行本地实例，在终端输入自己的密钥。不是把访客密钥交给作者服务器。

## 已实现

`scripts/run_local_byok.py` 接收服务商、模型名称、端口与迁移确认。数据库连接串及密钥用隐式输入；服务商限千问、DeepSeek（深度求索模型服务）和离线模式。固定官方地址，不接受任意代理地址。

真实模式缺少模型或密钥则拒绝启动；不从旧环境或 `.env`（本地环境配置文件）回填模型凭证。关闭其他服务商凭证、远程向量与第三方追踪。密钥不放进链接、参数、源码或浏览器持久存储；仅以进程环境存在，不承诺管理员无法读取。不要提交完整环境转储或未经脱敏的日志。

## 预留契约

`LocalModelAccess`（本地模型接入参数）包含服务商、模型标识和密钥，文本表示排除密钥；`build_environment`（生成进程配置）是未来本地桌面启动器可复用的接入边界。

若以后做网页填写密钥，必须改为登录用户与会话绑定的配置，不能写入共享全局设置。以下是预留设计，**不是已开放的网络接口**：

| 操作 | 行为 | 禁止 |
| --- | --- | --- |
| 建立模型会话 | 鉴权后接收凭证，内存保存并设期限 | 密钥放进请求地址或全局设置 |
| 查看连接状态 | 只返回服务商、模型、是否配置与到期时间 | 返回原始密钥 |
| 模型请求 | 从当前账号会话取密钥，缺失则停止 | 回退到作者或他人密钥 |
| 退出、撤销、到期 | 停用凭证，取消关联任务 | 后台继续使用撤销密钥 |

公网还需要传输加密、日志脱敏、跨账号测试、服务商地址白名单和后台凭证生命周期。自带密钥解决费用归属，不能替代认证、数据库或后台服务器。
