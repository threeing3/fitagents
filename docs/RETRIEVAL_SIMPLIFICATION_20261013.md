# 检索简化交付

## 当前链路

账号、有效状态和有效期过滤 → 关键词与向量独立取候选 → 合并去重 → 两路等权 RRF（倒数名次融合） → 时效性与场景适用性调整 → 原有类别预算装入上下文。

只有关键词时不调用额外模型做重排。实体名称和规范实体值合并到关键词文本，不再单独查实体候选。近期记忆不再作为独立召回路线，无关的近期记忆不会因为新或重要就被补进结果。

## 唯一评分规则

每路名次从 0 开始，以 1/(61+rank) 融合。用可用路线的最大可能融合分归一化，防止没配置向量时整个分数减半。最终：

```text
final = relevance × (0.9 + 0.1 × temporal_score) + applicability_adjustment
```

无相关性则为 0；适用性仍采用原来的 ±0.1 有界调整。时效性继续沿用不同记忆类型的半衰期与保留底分；稳定健康事实不会按普通短期事件衰减。分数用于排名，不是校准后的概率或自动接受置信度。

去掉重复关键词原始分、重要性、风险和观点惩罚的额外加分。风险事实依然由现有风险召回类别、风险记录与上下文优先通道处理，不能把相似度加分当成安全保证。账号隔离、旧版本失效和纠错写入机制未变。

## 知识与评测

知识与案例的数据库路径改为独立关键词候选加向量候选取并集，使用共用 RRF；不再只对最近的几条或者向量候选做关键词评分。内置小知识库的关键词池最多 256 条，按编号稳定取样；超出该规模需要数据库侧全文索引或分页检索，本次不声称覆盖任意规模。文件内置知识的纯关键词路径保持兼容。

运行时与离线夹具评测使用同一融合及调整函数。夹具的候选池、向量来源与时间输入仍不同于真实数据库，不冒充真实召回或线上效果。关键词基线修正零分补齐行为，避免无关候选恰好满足答案标签。

## 验证与部署边界

验证合成数据上的无关记忆排除、实体元信息召回、策略适用性、时效性、旧版本过滤、用户隔离、风险上下文保留、知识独立双路候选与评测评分一致性。
