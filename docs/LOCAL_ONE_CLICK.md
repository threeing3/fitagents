# 本机一键启动

在项目根目录双击 `Start-FitAgent.cmd`，随后访问 http://127.0.0.1:8015/ 。
保留弹出的终端窗口，关闭应用时按 Ctrl+C。首次加载可能需要一分钟以上；浏览器先打开时请等终端显示服务地址后刷新。

这是针对当前机器已有环境的启动入口，不是从零安装器：需要已有 `.venv`、`web/dist`、`E:\PostgreSQL\bin\pg_ctl.exe` 和 `logs/postgres_isolated_20261002`。

## 启动行为

- 需要时启动 15432 端口的既有隔离演示数据库，不依赖 Docker Desktop。
- 核对数据库迁移版本、表和字段；不自动迁移、建库、重置或填入演示数据。
- 启动应用并提供已构建的前端；不会重新构建前端，源码改动后需要自行构建。
- 默认读取本地已有模型配置，聊天可能产生模型费用；每日调用限制沿用本地预览设置。
- 禁用自动后台任务，避免执行历史排队任务。因此后台定时跟进不是此入口的验收范围。
- 每次新启动生成临时登录签名，原账号数据不变，但可能需要重新登录。
- 已运行时只检查健康状态，不切换模型模式、不结束未知进程。

## 可选运行方式

在项目目录打开 PowerShell（命令终端）：

```powershell
.\Start-FitAgent.cmd -Offline
.\Start-FitAgent.cmd -CheckOnly -NoBrowser
```

离线模式不调用真实模型。检查模式仍会在数据库停止时启动它，但不启动应用。如果已有应用运行，以上选项不会改变它的当前模式。

数据库启动日志：`logs/postgres_oneclick.log`。应用错误显示在启动终端。本次后台启动验证日志另存于 `logs/oneclick_app_20261007.*.log`。

## 公共部署边界

本机入口不等于公共部署。公共演示使用独立数据库，不上传本地账号、聊天记录或数据库文件。免费托管实例的文件可能随重启丢失，完整执行追踪持久化必须另行验收；公共链接未发布前不能当作可用成果。
