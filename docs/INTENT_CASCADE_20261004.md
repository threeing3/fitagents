# 意图级联退出协议 v1

> 当前状态：级联机制保留为可选实验辅助，已不是主业务默认必经路径。主链路采用轻量分发，见 `LIGHTWEIGHT_DELEGATION_20261004.md`。以下内容描述可选级联的边界。

## 边界

退出分类不等于允许写入。所有结果继续通过风险下限、澄清协议、审批和业务执行检查。
accept 表示本层识别完整；escalate 表示升级语义解释。缺少动作参数由既有澄清协议处理，不需要重新猜意图。
本版本没有统一会话指代解析；模糊确认与取消不能加入无状态规则白名单。

## 已实现的接受范围

规则只接受整句白名单：问候、无附加要求的生成训练计划、指定今天/昨天/本周/上周的训练记录查询。
同时要求无次意图、风险为低。日期参数仍由业务层解析。缺少档案字段不影响意图明确，但会阻止执行并澄清。
其他消息强制进入现有语义决策路径，不再使用预设规则置信度作为独立退出依据。

## 示例向量层

已替换为本地 BGE-small-zh-v1.5 中文语义向量，ONNX Runtime 执行未量化模型；请求期间不联网。首次准备需要下载模型和安装项目内可选依赖。
固定合成例句的向量在进程内缓存，返回前三个示例的编号、意图和余弦相似度；第四层接收候选提示，但不能当作完整任务集合或正确概率。
未校准前不授权提前退出；缺少模型或向量无效时明确升级，不返回伪向量。
详细准备命令、真实诊断和边界见 `INTENT_SEMANTIC_VECTOR_20261004.md`。

## 模型与兜底

保留可选适配器、字段复核和当前供应商模型。Jev 已有可选客户端与门禁，但主业务入口未启用，没有真实调用效果；不配置不影响运行。
模型不可用/输出无效时保留规则回退，不将回退记成确定接受。
后续必须进一步收紧回退的副作用执行；已有写入和审批边界不由本策略替代。
provenance.cascade 记录策略版本、接受/升级原因和检索候选，现有路由事件携带该字段。

## 开放新的提前退出范围前

1. 示例库、校准集、冻结测试集分离，同模板及近重复不跨集合。
2. 标注完整任务集合、否定、约束、承接对象、预期动作或澄清。
3. 各任务分别选择分数门槛、竞争任务间隔、支持示例一致性条件。
4. 检查接受请求中的任务遗漏、错误新增和约束丢失；高风险与副作用单独验收。
5. 后级模型在真实残余困难样本上检查，不直接套用全量数据门槛。
6. 样本不足或出现不可接受错误，关闭该类提前退出；不得用小样本零错误宣称可靠。
